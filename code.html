Pipeline de Procesamiento

Arquitectura del script analítico para transformar transacciones crudas en cohortes listas para CRM.

01

Ingesta & Sanitización

Carga de retail_sales_dataset.csv con parseo de timestamps UTC y remoción de duplicados.

02

Cálculo de Parámetros RFM

Agrupación por CustomerID: días desde última compra, conteo de pedidos y gasto acumulado.

03

StandardScaler & Elbow Test

Normalización de distribución z-score y minimización de inercia intra-cluster para validación matemática de k=4.

04

K-Means Clustered Sync

Asignación de cluster ID y sincronización bidireccional directa hacia Klaviyo, Braze y BigQuery.

rfm_pipeline.py
Python 3.11
# 1. Cálculo de métricas RFM base
rfm = df.groupby('CustomerID').agg({
'InvoiceDate': lambda x: (snapshot_date - x.max()).days,
'InvoiceNo': 'count',
'TotalSpend': 'sum'
})
# 2. Estandarización y Machine Learning
scaler = StandardScaler()
rfm_scaled = scaler.fit_transform(rfm)
kmeans = KMeans(n_clusters=4, random_state=42)
rfm['Cluster'] = kmeans.fit_predict(rfm_scaled)
